# 实验 02 · 冻结 ViT 的前景分离质量与背景杂乱度（CUB-200-2011，n=1000）

日期：2026-09-11 · 设备：M1 Max / MPS · 三模型共 3000 次推理约 20 分钟

## 要回答的问题

实验 01 只看了 4 张图，其中一个观察是「最杂乱的那张（黄嘴杜鹃）DINOv3 没有优势」。
这一次用 1000 张图、有 ground truth 的分割 mask，把它做成一个能证伪的定量问题：

1. DINOv3 的密集特征是否真的比 DINOv2 更「干净」？干净是 **register** 的功劳还是 **Gram anchoring** 的？
2. 背景越乱，前景分离掉多少？**v3 是否在杂乱背景上失去优势？**

## 做法

- 数据：CUB-200-2011 test split 随机 1000 张（seed=0），官方鸟体分割 mask 当前景 GT，缩到 32×32 patch 网格
- 模型（都是 22M，架构可比，按 patch 网格对齐输入分辨率）：
  | key | timm 名 | 说明 |
  |---|---|---|
  | `dinov2` | `vit_small_patch14_dinov2` | 无 register |
  | `dinov2_reg4` | `vit_small_patch14_reg4_dinov2` | +4 register，无 Gram anchoring ← **对照组** |
  | `dinov3` | `vit_small_patch16_dinov3` | 4 register + Gram anchoring + 更大数据 |
- 前景 mask：**NCut**（patch 余弦相似度图上 Normalized Cut，Fiedler 向量二分，阈值取每图相似度中位数），见下面「方法上踩的坑」
- 指标：mask 与 GT 的 **IoU**；patch 与 4 邻域的平均余弦相似度（**平滑度**）
- 协变量：**杂乱度** = GT 背景区域的平均梯度幅值；**鸟体占比**
- 统计：bootstrap 95% CI、配对 Wilcoxon、三等分分层、Spearman / 偏相关

```bash
python experiments/scripts/bg_quant.py --n 1000
```

## 结果

### 1. DINOv3 前景分离明显更好，且不是 register 的功劳

| 模型 | IoU [95% CI] | 平滑度 |
|---|---|---|
| dinov2 | 0.560 [0.549, 0.572] | 0.784 |
| dinov2_reg4 | 0.549 [0.538, 0.561] | 0.830 |
| **dinov3** | **0.681 [0.665, 0.696]** | **0.949** |

- v3 比 v2 高 **+0.121 IoU**（配对 Wilcoxon p ≈ 1e-88）
- **加 register 没有帮到前景分离**：reg4 比 v2 反而低 0.011（p ≈ 3e-19，效应小但一致）。
  register 让特征更平滑了（+0.046），但平滑不等于更会分主体。
- 平滑度的提升 v2 → reg4 → v3 是 +0.046 → +0.119，register 只解释了约四分之一。

> 不能说的：「所以是 Gram anchoring 的功劳」。v3 和 reg4 之间除了 Gram anchoring 还差数据规模
> （17 亿 vs 1.4 亿）、patch 大小（16 vs 14）和训练配方。能说的是：**这个提升不来自 register**。

### 2. 「v3 在杂乱背景上没优势」——实验 01 的那个观察是个例，不成立

| 杂乱度 | n | dinov2 | dinov2_reg4 | dinov3 | v3 − v2 |
|---|---|---|---|---|---|
| 低 | 334 | 0.522 | 0.510 | 0.671 | +0.149 |
| 中 | 333 | 0.564 | 0.561 | 0.677 | +0.114 |
| 高 | 333 | 0.595 | 0.577 | 0.696 | +0.100 |

- v3 的优势随杂乱度**收窄**（0.149 → 0.100）但**没有消失**，高杂乱组仍 +0.10
- 更细的双重分层（鸟体大小 × 杂乱度），**9 个格子 v3 全部领先**，最小 +0.056（大鸟 + 高杂乱），最大 +0.201（中鸟 + 低杂乱）
- 黄嘴杜鹃那张落在「中鸟 + 高杂乱」格，该格平均 +0.136——它就是个 outlier

### 3. 一个反直觉的发现：DINOv2 反而在杂乱背景上分得更好，DINOv3 对杂乱度不敏感

- Spearman(IoU, 杂乱度)：v2 +0.092 (p=0.004)，reg4 +0.091，**v3 +0.012 (n.s.)**
- 怀疑是「天空背景 = 低杂乱 + 小鸟」的尺寸混淆，查了：杂乱度与鸟体占比相关只有 −0.096；
  控制鸟体大小后偏相关 v2 +0.114 (p<0.001)、v3 +0.027 (n.s.)——**效应是真的，不是混淆**
- 可能的解释（未验证）：均匀背景（天空/水面）上 NCut 对 v2 容易把背景自己切成两半；
  杂乱背景反而让鸟成为唯一「内部一致」的团块。v3 特征内部一致性高，两种背景下都稳。

### 4. 鸟体大小是最大的影响因素，所有模型都在小目标上吃亏

| 鸟体占比 | dinov2 | dinov2_reg4 | dinov3 |
|---|---|---|---|
| 小 | 0.386 | 0.380 | 0.485 |
| 中 | 0.588 | 0.580 | 0.749 |
| 大 | 0.708 | 0.688 | 0.810 |

32×32 网格下小鸟只占几十个 patch，任何方法都难。这是期末实验里值得单独控制的变量。

## 方法上踩的坑（都值得写进汇报）

1. **单图 PC1 不是前景轴。** 实验 01 用第一主成分 + Otsu 切前景，4 张图全局 PCA 时看着对，
   单张图就翻车（蓝黑雀：前景占比 63%，PC1 抓的是「左亮右暗」）。换成 NCut 后 PC1 版 IoU
   只有 0.31–0.36，NCut 版 0.55–0.68，**方法选错结论全错**（PC1 版会得出 reg4 ≈ v3）。
2. **TokenCut 的固定阈值 0.2 对 DINOv3 无效。** 三个模型的 patch 相似度中位数差三倍
   （v2 ≈ 0.2、v3 ≈ 0.6），固定阈值让 v3 的图几乎全连通、Fiedler 向量退化（黄嘴杜鹃切出 0%）。
   改为每图相似度中位数做阈值，各模型图密度都是 50%，可比。
3. **artifact 指标作废。** 原本用「范数 > median + 3·MAD 的 patch 比例」，结果 reg4 比 v2 高，
   和文献矛盾。换绝对阈值（范数 > 2× 中位数）三个模型全是 0%，最大范数/中位数只有 1.11–1.16
   ——**ViT-S 根本没有高范数 artifact token**（文献里主要在 ViT-L/g），相对阈值在紧分布上纯误报。
   报告里保留该列只为可追溯，不做任何结论。
4. **对比要按 patch 网格对齐**而不是按像素（实验 01 已记）。

## 已知局限

- 只有 ViT-S 一个尺寸；v3 的优势在 B/L 上是放大还是缩小不知道
- 杂乱度用背景梯度幅值定义，是纹理杂乱不是语义杂乱（草丛 vs 另一只鸟）
- NCut 是无监督方法，IoU 上限受方法本身限制，不代表特征的全部信息
- 单 seed（seed=0）；换 seed 再跑一遍能确认稳定性，成本 20 分钟
- 没有做 linear probe——「前景分得好」是否转化为「细粒度分类准」，是期末的主实验

## 对期末项目的含义

「更锐利 ≠ 更不依赖背景」这个假设在无监督前景分离这一层**没有得到支持**——v3 在所有杂乱度上都更好。
但这只是特征层面的证据。期末要做的是任务层面的：冻结特征 + 线性探针，用 SAM 抠主体做
原图 / 背景涂灰 / 背景替换，看**分类准确率**掉多少。前景分得好不等于分类时不偷看背景。
