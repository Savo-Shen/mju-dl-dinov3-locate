怎么看这些图

ViT 把图切成 N×N 个小方块（patch），每块输出一个 384 维向量，意思是「这一块是什么」。下面两张图都是从这些向量算出来的。

彩色图：模型给每一小块打的「标签」

384 维画不出来，用 PCA 找方差最大的 3 个方向当 R、G、B。

读法只有一条：颜色相近 = 特征相近 = 模型认为这两块是同一类东西。
  • 颜色本身没意义——每个模型自己做 PCA，DINOv2 的紫和 DINOv3 的绿不能对着比。要看的是边界干不干净、同一物体内部颜色统不统一。
  • 背景里的椒盐碎点 = 相邻两块明明是同一个东西，特征却差很多。这就是「邻域相似度」低在图上的样子。

黑白图：模型自己圈出的「主体」

白色 = 在模型特征看来自身最一致、和其余部分最不像、又不贴着画面边缘的那一团。全程没有任何标注，它没被告诉过「人」「鸟」是什么。

算法叫 Normalized Cut（Shi & Malik 2000；用在 DINO 特征上是 TokenCut, CVPR 2022），四步：

  1. 连成一张网：每个 patch 是一个点，任意两点之间连边，边的粗细 = 特征余弦相似度。同一个物体内部连得密，物体之间连得稀。
  2. 一刀切两半：找一条线把点分成两组，切断的边越细越好。
  3. 归一化惩罚小块：光看切断多少会切出孤零零一个角落。改看「切断的 ÷ 各组自己的总连接」——小块分母小、比值大，被惩罚。所以赢的不是面积最大的，是分得最干净、又不至于小到没意义的。
  4. 哪边是前景：切出的两组是对称的，用一个先验挑：主体一般不占满四条边，碰边界少的那组算前景。

第 2 步精确解是 NP-hard，实际解的是特征值问题 (D − W)v = λDv，取第二小特征值的向量（Fiedler 向量），符号就是分组。直觉：把网当弹簧，粗边硬、细边软，它找的是最软的那条缝。

为什么不圈别的区域

NCut 只切一刀，找的是全图最松的一条缝。想把画面里第二个物体也单独圈出来，要在切完后对每一半再切（递归 NCut），或者换 SAM 那种给点就出 mask 的方法。

数字

邻域相似度每个 patch 和上下左右邻居的平均余弦相似度。越高特征越平滑，彩色图里碎点越少。
cos 相似度中位数全图 patch 两两有多像。DINOv2 ≈ 0.2、DINOv3 ≈ 0.6，差三倍——所以 NCut 的阈值必须按每张图自适应（取中位数），固定 0.2 会让 DINOv3 的网全连通、切不开。
前景占比白色块占全图比例。主体大小的合理性检查：一只小鸟占 60% 肯定是切错了。

三个常见误读

不是「DINO 认为这块是主体」。DINO 只提供「谁和谁像」这张网，圈哪块是 NCut 决定的。
不是「最特别的」。NCut 只衡量分离度和内聚度，不衡量新奇或重要；一片纯色的墙一样能被圈出来。
不是「面积最大的」。面积只在归一化里起作用，用来惩罚太小的块。

局限

  • 只切两块：多个物体会合并（人 + 椅子）或只留一个。
  • 小目标吃亏：patch 太少，内部「密」得不够。
  • 特征分解 O(n³)：32×32 = 1024 点 0.1 秒；网格拉太大就慢了。
